Acerca del empleo
BICECORP está en búsqueda de Administrador de Base de Datos para la Gerencia de Tecnología.


El desafío del rol es ser el encargado de la gestión integral, administración y soporte estratégico de base de datos.




Las principales funciones:

Gestionar y resolver tickets de cambios, incidentes, problemas y/o requerimientos
Ejecutar todas aquellas actividades inherentes en entornos de base de datos.
Proveer soluciones rápidas y eficaces en situaciones de crisis que permitan restablecer los servicios
Realizar análisis, investigaciones y diagnósticos ante la presencia de incidentes y/o problemas
Implementar soluciones que permitan resolver incidencias u optimizar/mejorar la performance de las bases de datos
Documentar en la herramienta de gestión ITSM las tareas completadas, incluyendo detalle de las soluciones aplicadas, evidencia de los resultados y/u otra información relevante




¿Qué necesitas para postular?

Tener al menos 3 de experiencia en rol actual o similares.
Conocimiento SQL Server
Conocimiento Oracle
Disponibilidad para turnos rotativo 24/7
